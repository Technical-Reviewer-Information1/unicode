# Code Style and Conventions

## Language Style
- Japanese comments and strings throughout the application
- User-facing text is in Japanese
- Variable names and function names are in English

## Python Conventions
- Functions use snake_case naming (e.g., `bytes_to_hex`, `safe_encode`)
- Constants use UPPER_CASE (e.g., `ENCODING_INFO`)
- Docstrings in Japanese explaining function purpose
- Error handling with try/catch blocks
- Type safety with explicit error return values

## Streamlit Conventions
- Page configuration at the top
- Use of columns for layout organization
- Consistent use of emojis in headers and UI elements
- Progressive disclosure of information through sections
- Visual feedback with success/error messages
