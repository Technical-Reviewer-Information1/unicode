# Project Overview

## Purpose
This is a Unicode/character encoding educational web application built with Streamlit. The app teaches users about digital representation of characters, specifically:
- Character encoding systems (UTF-8, Shift_JIS, EUC-JP, ASCII)
- Conversion from characters to bytes and binary representation
- Bit and byte relationships
- Visual demonstration of how computers store text

## Target Audience
Educational tool for learning about character encoding and digital text representation.

## Main Features
1. Character encoding selection (UTF-8, Shift_JIS, EUC-JP, ASCII)
2. Character input and conversion to bytes/binary
3. Visual representation of bit/byte relationships  
4. Character encoding comparison
5. Educational explanations about bits, bytes, and character codes
