# Tech Stack

## Core Technologies
- **Python**: Main programming language
- **Streamlit**: Web framework for the educational application
- **pandas**: Data manipulation and display for tables/dataframes

## Dependencies
- streamlit: Web UI framework
- pandas: DataFrame operations and display

## File Structure
- `streamlit_app.py`: Main application file containing all the logic
- `requirements.txt`: Python dependencies
- `README.md`: Basic project documentation
- `.devcontainer/`: Development container configuration
- `.serena/`: Serena MCP server configuration
- `.claude/`: Claude configuration
